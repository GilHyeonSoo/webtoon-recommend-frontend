# Frontend — 웹툰 취향 퀴즈

흰색 배경과 Paperlogy 폰트 위에 검은 유리 원으로 답하는 분기형 퀴즈를 구현합니다. 질문별로 원이 2~4개 나타나며, 원 안의 답변을 선택하면 다음 질문으로 이동합니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
cd Frontend
npm ci
npm run dev
```

터미널에 출력된 로컬 주소를 엽니다. 기본 포트는 5173이며, 사용 중이면 다음 포트로 실행됩니다.

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

Vercel: Root Directory `Frontend`, Build Command `npm run build`, Output Directory `dist`.

## 질문과 화면

- 질문 은행은 22개입니다. 한 사용자에게는 선택한 분기에 따라 9~11개 질문을 보여줍니다.
- 시작 질문: **오늘 어떤 이야기에 빠지고 싶나요?**
- 공통 시작: 이야기의 느낌 → 세계관 → 이야기의 중심.
- 이야기의 중심을 선택하면 사랑 / 성장 / 미스터리 / 일상으로 분기합니다.
- 사랑: 사랑의 분위기 → 관계의 시작 → 배경 → 갈등 허용.
- 성장: 주인공 → 성장 방식 → 새로운 기회 → 목표 → 대결.
- 미스터리: 긴장감 → 공포 허용 → 중심 인물 → 진실을 밝히는 방식.
- 일상: 배경 → 읽고 난 뒤의 기분 → 고민의 깊이.
- 마지막 공통 질문: 완결·연재 → 무료 이용 → 플랫폼.
- 질문마다 2~4개의 원이 가로로 순차 등장합니다. 작은 화면에서는 원 크기와 간격을 줄이고 답변을 줄바꿈합니다.
- 답변은 원 안에 표시합니다. 선택 테두리와 원 아래 플랫폼 이름은 표시하지 않습니다.
- 이전 질문 / 처음부터를 지원합니다. 이전 답변을 바꾸면 기존의 이후 답변을 버리고 경로를 다시 계산합니다.
- 클릭·터치·Enter·Space로 답변합니다. 방향키와 Home / End는 원 사이의 초점만 이동합니다.
- 질문 전환 시 제목으로 초점을 옮기고 스크린리더에 질문과 답변 개수를 안내합니다.
- 답변은 React 상태에 저장하며 새로고침 시 초기화됩니다.

## 추천 v1

로컬 `data/webtoons/webtoons-{naver,kakao,kakao-page}.json`을 합친 **30작품 샘플**을 `src/data/webtoons.json`에 저장해 사용합니다. 데이터 API 목록 요청을 실행하지 않습니다. 기존 `src/api/webtoons.ts`는 후속 API 연동을 위해 유지합니다.

- 장르·태그를 정규화하고, 질문별 특징과 일치하면 가중 점수를 더합니다.
- 줄거리의 키워드 단서는 장르·태그의 절반 가중치로 반영합니다. 현재 구현은 규칙 기반 키워드 매칭이며, 세밀한 관계나 전개 분류의 정확성은 메타데이터 보강이 필요합니다.
- 정보가 없는 작품은 해당 특징을 미확인으로 취급하고, 취향에 맞는다는 이유를 생성하지 않습니다.
- 선택한 플랫폼과 완결·연재 조건을 유지합니다. 공포를 피하고 싶다고 답하면 공포 단서가 확인된 작품을 제외합니다. 정보가 없는 작품의 내용까지 보장하지는 않습니다.
- 무료 이용은 우선순위로 반영합니다. `isFree`와 `freeWaitHour`만으로 전 회차 무료를 단정하지 않습니다.
- 점수 순으로 최대 3작품과 추천 이유, 작품 소개, 이용 정보, 플랫폼 링크를 표시합니다.
- 취향 단서가 없으면 이용 조건을 기준으로 제안했다는 안내를 표시합니다.
- 조건에 맞는 작품이 없으면 빈 결과와 답변 변경 방법을 안내하며 조건을 임의로 완화하지 않습니다.

카카오페이지 샘플은 줄거리·장르·태그가 비어 있습니다. 전체 데이터 및 BFF 연동 단계에서 추천 후보와 메타데이터를 확장해야 합니다. 현재 다음 질문 선택은 주제별 분기 방식이며, 후보별 정보량에 따라 질문을 고르는 방식은 후속 확장 지점입니다.

## 그래픽과 폰트

- 배경색은 `#FFFFFF`입니다.
- 제공된 `Paperlogy-1.001`의 Regular (400), Medium (500), Bold (700)를 로컬 `@font-face`로 사용합니다.
- Three.js의 단일 WebGL 렌더러와 GLSL 셰이더가 유리 반사·굴절·빛 흡수를 표현합니다.
- 원의 DOM 변경을 관찰해 GPU 객체를 추가·해제하므로 질문별 원 개수 변경, 이전 질문, 재시작을 지원합니다.
- WebGL을 사용할 수 없거나 컨텍스트가 손실되면 CSS 유리 표현으로 전환합니다.
- 그래픽 모듈은 지연 로드합니다. 최대 DPR 1.75 / 30fps이며, 숨겨진 탭과 결과 화면에서는 연속 렌더링을 중단합니다.
- 모션 감소 설정에서는 애니메이션을 제거하고 이벤트 발생 시에만 다시 그립니다. 고대비 모드를 지원합니다.

## 기술 스택

React 19.3.0 / TypeScript 7.0.2 / Vite 8.3.3 / Three.js 0.186.1 / Vite React plugin 6.1.2. 정확한 버전과 lockfile을 저장했습니다.

## 검증

`npm test`의 13개 테스트가 질문 개수 제약, 네 가지 분기의 종료, 이전 답변 변경, 중복 클릭, 플랫폼·연재 조건, 취향 가중치, 메타데이터 누락, 무료 이용 우선순위, 공포 제외 및 실제 샘플 추천을 검증합니다. TypeScript 검사와 프로덕션 빌드를 실행하고, 브라우저에서 퀴즈 완료·동적 원 변경·키보드 조작·이전 질문·재시작·모바일 배치를 확인합니다.
